# atividadeHtml

Este projeto foi criado para fins didáticos e demonstrativos.

página apresenta o conceito do site, convidando o usuário a explorar o mundo da gastronomia, e oferece uma lista de receitas e utensílios essenciais na barra lateral.

Seções Principais
Introdução (P1tada): Apresentação da missão e filosofia do site, focada em técnica, paixão e afeto na cozinha.

Uma Viagem da Melhor Gastronomia: Detalha a abordagem do site para o aprendizado culinário, enfatizando técnicas e autonomia.

Aqui Você Vai Descobrir: Promove a coleção de receitas, desde o básico até pratos elaborados, com foco em "pulos do gato" e truques de chef.

Comunidade e Participação: Seções que incentivam o engajamento, apresentando os "Provadores Oficiais" e seus benefícios exclusivos (Acesso Antecipado, Materiais Exclusivos, Reconhecimento).

Sidebar (Barra Lateral): Contém uma Lista de Receitas (como Petit Gateau, Pizza, Yakissoba, etc.) e uma lista de Utensílios com links para pesquisa no Google.

Rodapé (Footer): Links para as redes sociais (Instagram, YouTube, Facebook) e uma página de cadastro (style2.cc).

💻 Tecnologias Utilizadas
O projeto foi construído utilizando as bases do desenvolvimento web:

HTML5: Estrutura e marcação de todo o conteúdo da página.

CSS3: (Mencionado no código com link rel="stylesheet" href="style.css") Responsável pela estilização e layout, transformando o conteúdo em uma experiência visual agradável.
